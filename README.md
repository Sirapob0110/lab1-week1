# Student API

## โครงสร้างโปรเจกต์

โปรเจกต์นี้เป็น REST API ที่พัฒนาด้วย Node.js และ Express โดยมีไฟล์หลักคือ `index.js` ซึ่งประกอบด้วยการสร้างเซิร์ฟเวอร์ การกำหนดข้อมูลจำลอง (Mock Data) และ Route สำหรับการทำงานแบบ CRUD ได้แก่

* GET /api/v1/students
* GET /api/v1/students/:id
* POST /api/v1/students
* PUT /api/v1/students/:id
* DELETE /api/v1/students/:id

ไฟล์ `package.json` ใช้กำหนดรายละเอียดของโปรเจกต์และ Dependency ที่จำเป็น ได้แก่ Express และ Nodemon

## หากมี Route เพิ่มขึ้นอีก 10 เส้นทาง จะเกิดปัญหาอะไร

เมื่อจำนวน Route เพิ่มขึ้น โค้ดในไฟล์ `index.js` จะยาวและซับซ้อนมากขึ้น ทำให้อ่าน แก้ไข และค้นหาโค้ดได้ยาก อีกทั้งยังเพิ่มโอกาสเกิดข้อผิดพลาดและการรวมโค้ดจากหลายคนจะทำได้ลำบาก ดังนั้นในการพัฒนาระบบจริงจึงควรแยก Route ออกเป็นไฟล์ย่อยด้วย `express.Router()` และแยกส่วนการทำงานออกเป็นโมดูล เพื่อให้โปรเจกต์ดูแลรักษาและขยายระบบได้ง่ายในอนาคต
