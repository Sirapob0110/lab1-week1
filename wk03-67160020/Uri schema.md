# URI Schema — โปรเจกต์ student-api

เอกสารนี้รวบรวม Endpoint ทั้งหมดของโปรเจกต์ `student-api` หลังปรับปรุงตามปฏิบัติการสัปดาห์ที่ 3
ให้ตรงตามมาตรฐาน RESTful (ใช้คำนามพหูพจน์, ตัวพิมพ์เล็ก, HTTP Method และ Status Code ที่เหมาะสม)

## Students

| Method | URI                     | คำอธิบาย                                              | Status Code ที่เป็นไปได้ |
| ------ | ----------------------- | ----------------------------------------------------- | ------------------------ |
| GET    | `/api/v1/students`      | ดึงรายชื่อนักศึกษาทั้งหมด                             | 200                      |
| GET    | `/api/v1/students/{id}` | ดึงข้อมูลนักศึกษารายบุคคล (รองรับ `?include=courses`) | 200, 404                 |
| POST   | `/api/v1/students`      | เพิ่มนักศึกษาใหม่                                     | 201, 400, 409            |
| PATCH  | `/api/v1/students/{id}` | แก้ไขข้อมูลนักศึกษาบางส่วน                            | 200, 404                 |

## Courses

| Method | URI                    | คำอธิบาย                 | Status Code ที่เป็นไปได้ |
| ------ | ---------------------- | ------------------------ | ------------------------ |
| GET    | `/api/v1/courses/{id}` | ดึงข้อมูลรายวิชารายบุคคล | 200, 404                 |

## GraphQL

| Method | URI        | คำอธิบาย                    |
| ------ | ---------- | --------------------------- |
| POST   | `/graphql` | Query/Mutation ผ่าน GraphQL |

## บันทึกการปรับปรุงจากสัปดาห์ที่ 2

| Endpoint เดิม                           | ปัญหาที่พบ                                 | การแก้ไข                                                |
| --------------------------------------- | ------------------------------------------ | ------------------------------------------------------- |
| `GET /api/v1/students/:id/full`         | ชื่อ `full` ไม่ใช่ชื่อ resource ที่เหมาะสม | เปลี่ยนเป็น `GET /api/v1/students/{id}?include=courses` |
| `POST /api/v1/students` (email ซ้ำ)     | เดิมตอบกลับ 400                            | เปลี่ยนเป็นตอบ 409 Conflict                             |
| ไม่มี Endpoint สำหรับแก้ไขข้อมูลบางส่วน | ขาด PATCH                                  | เพิ่ม `PATCH /api/v1/students/{id}`                     |

---

## หมายเหตุ

- ใช้ Query Parameter `?include=courses` เพื่อดึงข้อมูลรายวิชาที่นักศึกษาลงทะเบียน แทนการสร้าง Endpoint `/full`
- ใช้ Status Code ให้ตรงตามมาตรฐาน RESTful
  - **200 OK** : ดำเนินการสำเร็จ
  - **201 Created** : สร้างข้อมูลสำเร็จ
  - **400 Bad Request** : ข้อมูลไม่ถูกต้อง
  - **404 Not Found** : ไม่พบข้อมูล
  - **409 Conflict** : ข้อมูลซ้ำ (เช่น email ซ้ำ)
